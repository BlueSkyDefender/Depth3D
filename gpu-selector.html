The easy way to get Depth3D running.

GPU Selector installs ReShade, Depth3D and the add-ons for you. It can also force a game onto a specific GPU, which on a laptop is often the difference between the depth buffer working and not.

Download GPU Selector Documentation

Setting up Depth3D with it

  1. Install GPU Selector and open the Mods tab.
  2. On the ReShade card, pick a version and set Build Type to Full Add-on Support.
  3. Click Download ReShade, then Launch and point the wizard at your game.
  4. Deploy the Depth3D card. This also gives you the Enhanced Generic Depth add-on.
  5. Start the game and press Home.

Overwatch comes with Depth3D, so a game with a profile is already configured.

Deploying Enhanced Generic Depth also turns off ReShade's built-in Generic Depth in ReShade.ini. Two depth detectors fighting over the same buffer is the usual reason people see no change.

Which ReShade build

StandardAnti-cheat safe. Use it for online and multiplayer games. No add-on support, so no Generic Depth Mod.
Full Add-on SupportWhat Depth3D's add-ons need. Singleplayer only. It can trip anti-cheat in multiplayer.
4.9.1 LegacyThe last build before the 5.0 add-on split. For very old shader packs.

Using ReShade in competitive multiplayer can break a game's terms of service. Check the game's rules first.

Inject Mode

Some games block a normal ReShade install. Inject Mode loads ReShade into the running game instead of placing files next to it.

Use it for:

  • Microsoft Store and UWP games, which do not allow DLL placement
  • Games with file integrity checks
  • EAC protected games
  • Anything where a normal install refuses to load

It also brings a custom overlay key, useful if Home is awkward on your keyboard, and gamepad navigation for the ReShade menu. Handy when you are sitting back from a 3D TV.

What else it does

Picks the GPU
Forces a game onto the graphics card you choose. On hybrid laptops and dual GPU desktops this is often what makes the depth buffer appear at all.
Finds your games
Scans Steam, Epic, GOG, EA App, Ubisoft Connect, Xbox, Battle.net, Amazon Games and itch.io. You can add your own too.
Emulators
ROM folder scanning and per emulator settings. Overwatch has profiles for the common emulators, so the two line up.
Translation layers
DXVK, VKD3D-Proton, dgVoodoo2, WineD3D and Zink. When Overwatch says a game needs DXVK or dgVoodoo2, this is where you get it.
Runs on Linux
Under Wine it adapts the install on its own, including the Vulkan layer setup.

Requirements

SystemWindows 10 or later, 64 bit. Linux users run it under Wine.
Also needsThe WebView2 runtime, already installed on most Windows 10 and 11 systems.
